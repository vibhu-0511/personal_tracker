# Blueprint errata

Task B1-01. This file resolves the contradictions and gaps in the Forge blueprint so that build tasks have one set of numbers to follow. Where this file and the blueprint disagree, this file wins.

Sources: BT = docs/plan/blueprint.txt, BH = docs/forge-blueprint.html (not edited), B1 = docs/plan/research/B1-report.md ("Gaps and contradictions", 22 items, numbered E-01 to E-22 below in the same order), plan = docs/plan/plan.json. Task ids (R1-06, X1-17 and so on) refer to plan.json.

Status values: `Resolved` means the decision is final for the plan. `OPEN (Dn)` means the answer belongs to the user; the default from docs/plan/OPEN-DECISIONS.md is assumed so work does not block, and the row is revisited when the user changes the Status cell for Dn.
